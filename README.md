
# AI Disease & Demographic Prediction App

This repository contains a full-stack, web-based AI screening application powered by Natural Language Processing (NLP) and Machine Learning. The system processes textual user inputs, applies advanced feature encoding and text vectorization, and delivers real-time diagnostic or predictive insights through an interactive Flask web interface.

## 🚀 Features

* **NLP-Driven Analysis:** Utilizes Term Frequency-Inverse Document Frequency (`TF-IDF`) vectorization to process text-based inputs.
* **Multi-Stage Feature Encoding:** Integrates custom pre-trained label encoders for handling categorical features like gender and target classifications seamlessly.
* **Dual-Page Web Interface:** Features a dedicated landing page for data input and a standalone results page for displaying detailed predictive analytics.
* **Dynamic Visuals:** Leverages custom background graphics and motion-based GIF themes for an engaging user experience.

---

## 🛠️ Tech Stack

* **Backend:** Python, Flask
* **Machine Learning & NLP:** Scikit-learn, Pandas, NumPy
* **Frontend:** HTML5, CSS3, JavaScript (Asynchronous requests)
* **Model Serialization:** Pickle (`.pkl`)

## ⚙️ Installation & Setup

Follow these steps to run the application locally:

### 1. Clone the Repository

```bash
git clone https://github.com/MaryumHayat/AI_project_Sleep_Disorder_Prediction.git
cd ai-project

```

### 2. Set Up a Virtual Environment

```bash
# Create environment
python -m venv venv

# Activate on Windows:
venv\Scripts\activate
# Activate on macOS/Linux:
source venv/bin/activate

```

### 3. Install Required Packages

Ensure you have the core libraries installed:

```bash
pip install flask scikit-learn pandas numpy

```

### 4. Run the Web Application

```bash
python app.py

```

Open your browser and navigate to `http://127.0.0.1:5000/`.

## 🧠 Machine Learning Pipeline

The backend utilizes an optimized pipeline to handle both structured demographic features and unstructured raw text:

1. **Text Vectorization:** User text input is vectorized using the pre-trained `tfidf.pkl` weights to extract linguistic features.
2. **Categorical Encoding:** Inputs such as gender are dynamically transformed using `gender_encoder.pkl`.
3. **Inference:** The processed feature array is fed into the predictive model (`model.pkl`).
4. **Decoding:** The numerical output is mapped back to its human-readable class name using `target_encoder.pkl`.
